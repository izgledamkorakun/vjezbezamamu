# 🌸 Vježbaonica

Mala web aplikacija na hrvatskom za jutarnje/večerne vježbe za zatezanje trbuha.

- ✅ Sve vježbe **bez opreme** — na krevetu ili na prostirci za vježbanje
- ✅ Nikad se ne oslanja na dlanove (pogodno za osjetljive zglobove ruku)
- ✅ **Animirane** vježbe s opisom izvođenja korak po korak
- ✅ Tajmer, dnevni napredak, motivacije
- ✅ Radi **offline** — cijela je aplikacija jedna datoteka (`index.html`)

---

## 🚀 Kako objaviti na GitHub Pages (besplatno, ~5 minuta)

### 1. Napravi repozitorij
1. Prijavi se na [github.com](https://github.com) (besplatan račun).
2. Desno gore klikni **`+` → New repository**.
3. Daj mu ime, npr. `mamina-vjezbaonica`, ostavi **Public** i klikni **Create repository**.

### 2. Učitaj datoteke
1. Na novoj stranici klikni link **„uploading an existing file"**.
2. Povuci (drag & drop) obje datoteke: **`index.html`** i **`README.md`**.
3. Klikni zeleni gumb **Commit changes**.

### 3. Uključi GitHub Pages
1. U repozitoriju idi na **Settings → Pages** (lijevi izbornik).
2. Pod *Build and deployment*: **Source: Deploy from a branch**, **Branch: `main`**, folder **`/ (root)`** → **Save**.
3. Pričekaj 1–2 minute. Stranica će biti dostupna na:

   **`https://TVOJE-KORISNIČKO-IME.github.io/mamina-vjezbaonica/`**

   (točan link piše u Settings → Pages, zelenom okviru.)

### 4. Instaliraj mami na mobitel
1. Pošalji joj link gore na WhatsApp/Viber.
2. Ona otvori link u **Chromeu**.
3. Tapne **⋮ → „Dodaj na početni zaslon"**.
4. Na ekranu joj je ikona 🌼 i aplikacija se otvara preko cijelog ekrana — kao svaka druga app.

## 📁 Datoteke

| Datoteka | Opis |
|---|---|
| `index.html` | Cijela aplikacija |
| `manifest.json` | Podaci za „instalaciju" na početni zaslon (ime, boje, ikone) |
| `icons/` | App ikone u svim veličinama (192, 512, maskable, apple-touch, favicon) |
| `README.md` | Ove upute |

⚠️ **Važno:** učitaj u repozitorij **sve zajedno** — `index.html`, `manifest.json`, `README.md` i cijeli folder `icons/`. Ako ti GitHub traži, povuci sve odjednom drag & dropom.

---

## 💡 Alternative GitHubu

Ne želiš GitHub? Datoteku `index.html` možeš:
- poslati direktno na mobitel (WhatsApp kao *datoteku*) — otvara se u Chromeu i radi potpuno offline, ili
- povući na [Netlify Drop](https://app.netlify.com/drop) (također besplatno hosting; povuci cijelu mapu).
